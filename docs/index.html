1. Overview & Architecture

DevicePassport is a full-stack hardware health certification, digital warranty, and inventory management platform designed specifically for the refurbished computer and laptop retail market.

Unlike standard generic web applications that require external database provisioning, DevicePassport leverages Node.js built-in node:sqlite. It delivers zero-latency local database storage with daily automated point-in-time snapshots and zero third-party cloud database costs.

⚡ Hardware Agent

Custom Windows PowerShell V4 Agent for direct battery cycle, SSD SMART, and stress test inspection.

🏷️ Physical Asset QR Labels

Printable 40 × 25 mm lid stickers and 60 × 30 mm intake labels with tamper-proof signatures.

🛡️ Digital Warranties

Customer self-service claim portal with photo uploads and live private tracking timeline.

📊 Precision P&L Finance

Integer-cent accounting deducting purchase price, parts, and warranty costs for exact gross margin.

2. 3-Minute Quick Start

Ensure you have Node.js 22.13.0 or higher installed on your system.

Step 1: Install Dependencies

cd device-passport
npm install

Step 2: Start Development Server

npm run dev

Open http://localhost:3000 in your browser.

Default Admin Credentials (Local Development):
Email: owner@lapmart.lk (or demo@devicepassport.example)
Password: devicepass

Step 3: Run Smoke Verification

Verify that your local SQLite database, security headers, restore snapshots, and rate-limiting are 100% operational:

npm run smoke

3. Docker Deployment (Recommended for Production)

DevicePassport includes a production-ready Dockerfile and compose.yaml. The database is stored inside a persistent volume so updates never overwrite your records.

# Build and start container in background
docker compose up -d --build

# Inspect running container logs
docker compose logs -f

Your application is now live at http://localhost:3000 with health checks running every 30 seconds.

5. Windows Tester V4 Hardware Agent

The crown jewel of DevicePassport is the native Windows Hardware Diagnostic Agent. Technicians run this tool directly on laptops being tested before sale.

Installation on Technician Laptops

  1. Sign in as Owner and go to Settings → Windows tester stations.
  2. Click Create station (e.g., "Bench Laptop #1") and copy the Station Token.
  3. Download the agent bundle from the dashboard or copy tools/windows to a USB stick.
  4. Double-click install-device-passport-tester.cmd on the laptop. It installs for the current user and adds desktop shortcuts.
  5. Enter the shop server URL and paste the Station Token. The token is encrypted using Windows DPAPI for the current user.

6. Guided Interactive Hardware Checks

When running the agent, the technician is guided through 6 critical hardware validations:

  • 6-Color Dead-Pixel Inspection: Full-screen cycling (Red, Green, Blue, White, Black, Gray) to reveal panel defects.
  • 60-Key Keyboard Matrix Tester: Real-time keypress listener with visual highlight of stuck or non-responsive keys.
  • Native Camera Preview & Capture: Captures webcam photo evidence stored directly in the signed diagnostic report.
  • Stereo L/R Audio Tone: Dual-channel frequency tone generation to verify both left and right speaker cones.
  • USB & Port Detection: Automatic hardware discovery of connected flash drives, external monitors, and chargers.
  • Battery & SSD SMART Telemetry: Collects exact charge cycle counts, wear level (%), power-on hours, and drive temperature.

8. Digital Warranty & Public QR Passports

Every inspected device receives a Public QR Device Passport and a Private Customer Warranty Card:

  • Public Passport: Scan the 40 × 25 mm sticker on the laptop lid to see hardware specs, battery health, SSD wear, and test evidence. Buyers love this transparency!
  • Customer Warranty Card: Upon sale activation, a private QR warranty card is issued. The customer can file warranty claims without creating an account and track live technician updates privately.
  • Internal Job Sheet: Technicians can print an authenticated A4 repair sheet for the physical repair bench with customer signatures.

9. Automated Backups & Safety Restores

DevicePassport ensures your data is never lost:

  • Daily Automatic Snapshots: Automatically generates SQLite backups retained for 14 days.
  • Guarded Restore: Restoring a backup requires the Owner password and exact text confirmation RESTORE. A pre-restore safety snapshot is automatically created before any database swap.

10. Production Deployment & Cloud Hosting Guide

DevicePassport is engineered for production reliability across self-hosted and cloud environments. Database and storage hosting depend on your deployment architecture:

A. Persistent Production Deployment (Recommended for Local / VPS)

The standard SQLite database requires a persistent disk volume to prevent data loss across restarts:

  • Docker & Docker Compose (Included): Deploy using the included Dockerfile and compose.yaml. The database is stored on a mounted persistent volume at /app/.data, ensuring uninterrupted data retention.
  • Linux VPS (Ubuntu / Debian on Hetzner, DigitalOcean, Linode, AWS EC2): Clone the repository, configure .env.production, and run docker compose up -d --build behind an NGINX or Caddy reverse proxy with automated SSL.
  • Render (Managed Docker): Deploy using the included render.yaml blueprint. A paid instance with a persistent disk attached at /app/.data is required for SQLite durability.

B. Serverless Cloud Production (Vercel / Supabase / Neon PostgreSQL)

For scalable, zero-maintenance serverless cloud deployment:

  • PostgreSQL Database: Connect your serverless Next.js app to any PostgreSQL database (such as Neon.tech or Supabase) by supplying the DATABASE_URL=postgres://... environment variable. The built-in dual-database engine automatically activates PostgreSQL mode.
  • Cloudflare R2 Object Storage: Store diagnostic photos and warranty evidence in Cloudflare R2 by setting R2_BUCKET_NAME, R2_ACCESS_KEY_ID, and R2_SECRET_ACCESS_KEY for zero egress fees.

C. Disposable Live Preview Demo vs Production

Note on our Live Demo: Our public online demo (hosted on Netlify) is configured as a stateless, disposable preview intended solely for buyer evaluation. For real-world workshop records, customer warranties, and financial ledgers, use the persistent Docker deployment or PostgreSQL cloud configuration described above.

11. FAQ & Troubleshooting

Q: Can customers edit their warranty or fake test reports?

No. Every Windows report is cryptographically signed using per-station HMAC-SHA256 tokens. The server validates that submitted data matches Tester V4's signed payload and rejects modified or replayed reports.

Q: Can I use this with barcode scanners and label printers?

Yes! The 40 × 25 mm asset stickers and 60 × 30 mm intake labels are formatted for standard thermal label printers (Brother, Zebra, Xprinter).
